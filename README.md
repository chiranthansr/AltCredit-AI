# AI Credit Risk Assessment System

## Overview

An AI-powered Credit Risk Assessment System that predicts a user's creditworthiness based on financial information and a risk questionnaire.

The application is built using FastAPI, MongoDB, Machine Learning, HTML, CSS, and JavaScript.

---

## Features

- User Registration
- User Login
- Consent Collection
- Credit Information Collection
- Risk Assessment Questionnaire
- Machine Learning Credit Score Prediction
- Dynamic Dashboard
- MongoDB Database Integration

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AltCredit-AI.git
```

Move into the project

```bash
cd AltCredit-AI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run FastAPI

```bash
uvicorn main:app --reload
```
